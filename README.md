# Sylvan B

Rust developer focused on desktop software, emulation, and backend systems.

## Selected work

- [CareerWatch](https://github.com/SylvanB/career-watch) - Job-change monitoring SaaS built with Rust, Axum, PostgreSQL, and Astro.
- [Dithering SOD](https://github.com/SylvanB/dithering-sod) - Native image-processing application for palettes, dithering, halftoning, and composable effects.
- [CHIP-8 Emulator](https://github.com/SylvanB/chip8-rs) - CHIP-8 emulator with an interactive debugger and disassembler.
- [Apple Music Presence](https://github.com/SylvanB/apple_music_presence) - macOS daemon that publishes Apple Music playback to Discord Rich Presence.
